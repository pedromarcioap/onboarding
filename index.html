Como este Site se Comunica com a sua VPS

ARQUITETURA N8N + EVOLUTION API V2

O Fluxo em 4 Passos Exatos:

1
O cliente preenche o formulário: Os dados (nome da mentoria, telefone VIP, link de agenda) são enviados via requisição POST para o Webhook do seu n8n.
2
O n8n processa na sua VPS: Salva as diretrizes do cliente (no Data Table) e chama a Evolution API localmente: POST /instance/create.
3
A Evolution API gera o QR Code: Retorna a imagem do QR Code em Base64 para o n8n, que repassa diretamente de volta para a tela do navegador do cliente.
4
O cliente lê o QR Code com o celular: A sessão é conectada na hora na Evolution API da sua VPS. Zero senhas expostas e zero arquivos para o cliente baixar!

Deixe em branco para rodar no Modo Demonstração (Sandbox) imediato, ou insira a URL do seu n8n para gerar QR Codes reais da sua Evolution API.
